Файлы конфигурации загрузки Raspberry Pi
========================================

На этапе загрузки, Raspberry Pi использует набор конфигурационных файлов, находящихся в корневом разделе microSD-карты (обычно `/boot`). Эти файлы определяют поведение загрузчика, параметры ядра, включение интерфейсов и отладку.

Главные файлы:
--------------

1. **config.txt**



   - Основной файл конфигурации загрузки, интерпретируется `start.elf` (GPU).
   - Используется для:
     - Включения UART
     - Настройки частоты процессора/памяти
     - Подключения overlays (например, I2C, SPI, дисплеи)
     - Отключения Bluetooth, камеры и пр.

   Пример:
   ::

       enable_uart=1
       gpu_mem=16
       dtoverlay=disable-bt
       dtparam=i2c_arm=on
       disable_splash=1

2. **cmdline.txt**



   - Передаёт параметры ядру Linux при загрузке.
   - Содержит одну строку с параметрами через пробел.
   - Пример:


       console=serial0,115200 console=tty1 root=/dev/mmcblk0p2 rw rootwait quiet

   Полезные параметры:
     - `console=serial0,115200`  вывод лога загрузки на UART
     - `root=/dev/...`  корневая файловая система
     - `quiet`  убирает лишние сообщения ядра

3. **kernel.img / kernel7.img / kernel8.img**


   - Собственно, бинарное ядро Linux. Выбирается по архитектуре:
     - `kernel.img`  ARMv6/7
     - `kernel7.img`  ARMv7 (RPi 2/3)
     - `kernel8.img`  ARMv8 (64-бит)

4. **overlays и device trees**



   - Расширяют стандартное устройство, добавляя поддержку периферии
   - Файлы: `*.dtb`, `overlays/*.dtbo`
   - Активируются через `config.txt`:
   

         dtoverlay=uart1
         dtoverlay=spi0-1cs

Где они находятся:
------------------

Все эти файлы хранятся на **разделе boot** (FAT32), доступном как `/boot` внутри Raspberry Pi, или как обычный диск, если microSD подключена к ПК.

Отладка и безопасность:
-----------------------

- Ошибка в `config.txt` может привести к "чёрному экрану"
- Используйте `hdmi_force_hotplug=1` и `config_hdmi_boost=4` при проблемах с выводом
- Не забудьте `enable_uart=1` для доступа к UART в критических ситуациях
