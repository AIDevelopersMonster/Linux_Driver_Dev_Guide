Методы сборки Embedded Linux
=============================

Рассмотрим три способа:

1. Ручная сборка:
-----------------

- Скачать исходники ядра и BusyBox
- Сконфигурировать и собрать вручную
- Создать rootfs (минимальный набор файлов)
- Смонтировать `/dev`, `/proc`, `/sys`

2. Buildroot:
-------------

- Меню-конфигуратор: выбрать пакеты, ядро, BusyBox
- Сборка полной системы: `make`
- Поддержка initramfs, systemd, SSH, Python, Qt и др.
- Простой путь для embedded-разработки

3. Yocto:
---------

- Фреймворк для сборки собственных Linux-дистрибутивов
- Meta-слои, зависимости, пакеты, рецепты
- Поддерживает множества архитектур
- Используется в промышленных решениях

Выбор:
------

-  Ручная  обучение, контроль, кастомизация
-  Buildroot  быстро, эффективно
-  Yocto  гибко, масштабируемо, сложно
