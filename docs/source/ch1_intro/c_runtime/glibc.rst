GLIBC: стандартная библиотека языка C
=====================================

`glibc` (GNU C Library)  это основная библиотека языка C в Linux. Она обеспечивает интерфейс между приложениями и ядром Linux через системные вызовы.

Что делает glibc:
-----------------

- Стандартные функции: `printf`, `malloc`, `fork`, `open`, `read`, `write`, `exit`
- Обёртки над системными вызовами (`open()`  `syscall(SYS_open, ...)`)
- Поддержка потоков (pthreads), математических функций, строк, времени
- Стандарт POSIX API

Где находится:
--------------

Обычно: `/lib/arm-linux-gnueabihf/libc.so.6`

Проверка версии:
::

    ldd --version
    strings /lib/arm-linux-gnueabihf/libc.so.6 | grep GLIBC

Важно:
------

glibc  ядро. Это userspace-библиотека, которая вызывает syscalls, передавая работу в ядро.
