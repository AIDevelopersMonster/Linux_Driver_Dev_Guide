Монтирование файловых систем: /etc/fstab
========================================

Файл `/etc/fstab` определяет, какие файловые системы монтируются при запуске.

Пример:
::

    proc            /proc           proc    defaults          0       0
    /dev/mmcblk0p1  /boot           vfat    defaults          0       2
    /dev/mmcblk0p2  /               ext4    defaults,noatime  0       1

Полезные опции:
- `nofail`  продолжить загрузку, даже если устройство не найдено
- `noatime`  отключить обновление времени доступа к файлам
- `defaults`  стандартный набор монтирующих опций
