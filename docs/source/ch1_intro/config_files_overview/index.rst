Обзор системных конфигурационных файлов
=========================================

После загрузки ядра Linux управление переходит в пространство пользователя (userspace), где поведение системы задаётся конфигурационными файлами.  
В этом разделе мы изучим ключевые конфигурационные точки, влияющие на загрузку, монтирование файловых систем, запуск модулей и пользовательских скриптов.
