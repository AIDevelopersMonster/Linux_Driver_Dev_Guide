Настройка IP-адреса на хост-компьютере
======================================

Если вы подключаете Raspberry Pi 3 B+ напрямую к компьютеру по Ethernet (без роутера), необходимо задать **статический IP-адрес** на хосте и Raspberry Pi.

Цель:
-----

- Обеспечить стабильную точку доступа между ПК и Raspberry Pi
- Избежать зависимости от DHCP/роутера

Linux (Ubuntu/Debian):
----------------------

1. Узнайте название интерфейса:
::

    ip a

2. Назначьте IP вручную:
::

    sudo ip addr add 192.168.137.1/24 dev enp3s0
    sudo ip link set enp3s0 up

3. Проверьте:
::

    ip addr show enp3s0

Windows:
--------

1. Откройте:
   Панель управления  Сетевые подключения

2. Правый клик по Ethernet  Свойства

3. Найдите и откройте "Протокол IPv4 (TCP/IPv4)"

4. Установите вручную:
::

    IP-адрес:            192.168.137.1
    Маска подсети:       255.255.255.0
    Основной шлюз:       (можно оставить пустым)

Настройка IP на Raspberry Pi:
-----------------------------

Откройте файл:
::

    sudo nano /etc/dhcpcd.conf

Добавьте в конец:
::

    interface eth0
    static ip_address=192.168.137.2/24
    static routers=192.168.137.1
    static domain_name_servers=8.8.8.8

Сохраните и перезагрузите Pi:
::

    sudo reboot

Проверка:
---------

На ПК:
::

    ping 192.168.137.2
    ssh pi@192.168.137.2

На Raspberry Pi:
::

    ping 192.168.137.1
