Настройка сетевого подключения между RPi и хостом
==================================================

В этом разделе вы научитесь устанавливать сетевое соединение между Raspberry Pi 3 и вашим хост-компьютером с помощью Ethernet или USB-гаджета. Вы узнаете, как назначить IP-адреса, проверить связь и использовать SSH для удалённого доступа.
