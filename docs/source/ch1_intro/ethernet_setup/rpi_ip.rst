Назначение статического IP-адреса на Raspberry Pi
=================================================

Чтобы Raspberry Pi 3 B+ всегда имела один и тот же IP при прямом соединении с ПК, зададим статический IP в её настройках сети.

Редактирование dhcpcd.conf:
---------------------------

Откройте конфигурацию:
::

    sudo nano /etc/dhcpcd.conf

Добавьте в конец файла:
::

    interface eth0
    static ip_address=192.168.137.2/24
    static routers=192.168.137.1
    static domain_name_servers=8.8.8.8

Пояснение:
----------

- `192.168.137.2`  IP Raspberry Pi
- `192.168.137.1`  IP хост-компьютера (ПК)
- DNS через Google (`8.8.8.8`)

Сохраните файл и перезагрузитесь:
::

    sudo reboot

Проверка:
---------

На Pi:
::

    ip a
    ping 192.168.137.1

На хосте:
::

    ping 192.168.137.2
    ssh pi@192.168.137.2

Теперь у вас стабильное прямое соединение Raspberry Pi  ПК.
