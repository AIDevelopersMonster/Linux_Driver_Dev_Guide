Иерархия файловой системы (FHS)
===============================

Filesystem Hierarchy Standard (FHS)  это стандарт размещения каталогов и файлов в Linux.

Ключевые каталоги:
-------------------

- `/bin`  базовые утилиты (sh, ls, cp)
- `/sbin`  системные команды (init, ifconfig)
- `/etc`  конфигурационные файлы
- `/usr`  вторичная и расширенная система (программы, библиотеки)
- `/var`  переменные данные (логи, почта)
- `/home`  домашние директории пользователей
- `/lib`, `/lib64`  общие библиотеки
- `/dev`, `/proc`, `/sys`  виртуальные и псевдофайловые системы
- `/boot`  ядро и загрузочные файлы
- `/tmp`  временные файлы

Стандарты:
----------

Официальный стандарт: https://refspecs.linuxfoundation.org/fhs.shtml

Полезно:
--------

Понимание FHS важно при создании rootfs, построении initramfs, организации embedded-систем.
