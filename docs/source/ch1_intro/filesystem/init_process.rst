Первый процесс в Linux: init
============================

После загрузки ядра, Linux запускает первый userspace-процесс  это `init`.

Исторически:
------------

- `/sbin/init`  классический init (SysVinit)
- `/lib/systemd/systemd`  современный systemd

Как определяется:
------------------

Через `cmdline.txt` параметр:
::

    init=/sbin/init

или по умолчанию (ядро ищет `init`, `linuxrc`, `initrd`)

Альтернативы:
-------------

- busybox init  встраиваемые системы
- runit, OpenRC, systemd

Значение:
---------

`init` запускает остальные процессы системы, монтирует диски, поднимает службы, интерфейсы.  
Без корректной инициализации система не сможет завершить загрузку.
