Подключение по UART (USB-TTL) и использование Minicom
======================================================

UART (Universal Asynchronous Receiver/Transmitter)  это простой и надёжный способ получить доступ к логам ядра и консоли Raspberry Pi без HDMI или SSH.

---

Что понадобится
---------------

- USB-TTL адаптер (например, CP2102, FT232RL)
- Три провода: RX, TX, GND
- Установленная утилита `minicom` или `screen`
- Raspberry Pi 3 с RPi OS

---

Подключение
------------

Подключите USB-TTL адаптер к Raspberry Pi следующим образом:

+----------------------+-------------------+
| Адаптер              | Raspberry Pi 3    |
+======================+===================+
| GND                  | GND (Pin 6)       |
+----------------------+-------------------+
| TXD                  | RX (Pin 10)       |
+----------------------+-------------------+
| RXD                  | TX (Pin 8)        |
+----------------------+-------------------+

>  Не подключайте VCC с адаптера, если он питается от USB  RPi уже получает питание от своего источника.

---

Настройка UART в RPi OS
-----------------------

Убедитесь, что UART включен:


sudo raspi-config
# -> Interface Options -> Serial Port -> enable
