Общее представление о ядре Linux
================================

Ядро Linux выполняет функции управления аппаратным обеспечением и обеспечивает интерфейс между оборудованием и пользовательским ПО.

Ключевые задачи:
----------------

- Планирование процессов (scheduler)
- Управление памятью
- Работа с файловыми системами
- Сетевой стек
- Работа с драйверами устройств
- Виртуализация и безопасность

Ядро может быть:
----------------

- Монолитным (как в Linux)
- Микроядерным (например, Minix, QNX)

Архитектура ядра Linux:
------------------------

::

    [ Пользовательское пространство ]
           |
    [ Системные вызовы (syscalls) ]
           |
    [ Ядро: планировщик, драйверы, подсистемы ]
           |
    [ Железо ]

Ядро бывает:
- Vanilla (чистое ядро от kernel.org)
- Патченое (например, Raspberry Pi Kernel с поддержкой устройств)
