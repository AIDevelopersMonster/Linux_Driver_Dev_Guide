Файл cmdline.txt  параметры запуска ядра Linux
===============================================

Файл `cmdline.txt`  это **однострочный список параметров**, которые передаются ядру Linux при загрузке.  
Располагается на FAT-разделе `/boot` и читается `start.elf`.

Пример:

::

    console=serial0,115200 console=tty1 root=/dev/mmcblk0p2 rw rootwait quiet

Ключевые параметры:
--------------------

- `console=serial0,115200`  вывод ядра на UART
- `root=/dev/...`  путь к корневой файловой системе
- `rootwait`  подождать, пока rootfs станет доступен
- `rw` / `ro`  монтировать rootfs как читаемо-записываемую или только для чтения
- `quiet`  скрыть лишние сообщения при загрузке
- `init=/sbin/init`  указать процесс, который будет первым

Полезные советы:
----------------

- Не переносите строку на несколько линий  она должна быть **одна строка**
- Между параметрами  **пробелы**, а не запятые
- Убедитесь, что указанное `root=` устройство реально существует и доступно
