Этапы запуска ядра Linux
=========================

После передачи управления от `start.elf` ядру (`kernel.img`) начинается запуск ядра Linux.

Ключевые этапы:

1. **Загрузка ядра (kernel.img)**  
   GPU копирует ядро в память и передаёт управление.

2. **Инициализация архитектуры (arch_init)**  
   Настройка базовых регистров и структуры устройства (ARM).

3. **Разбор Device Tree (DTB)**  
   Ядро использует `.dtb` для определения оборудования (периферия, GPIO, тактирование).

4. **Монтирование корневой файловой системы (initramfs / rootfs)**  
   Ядро ищет и монтирует `root=...`, указанное в `cmdline.txt`.

5. **Запуск первого процесса (usually init/systemd)**  
   Запускается `/sbin/init`, `systemd` или другой указанный процесс.

6. **Дальнейшая загрузка userspace**  
   Запускаются скрипты `/etc/rc.d`, `systemd-units`, сервисы.

Важно:
-------

- Ошибки на этом этапе  "Kernel panic"
- Всё зависит от правильных параметров в `cmdline.txt` и наличии правильного `rootfs`
