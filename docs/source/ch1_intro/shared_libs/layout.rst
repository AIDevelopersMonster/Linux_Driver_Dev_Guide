Размещение и подключение общих библиотек
========================================

Где находятся:
--------------

- `/lib`, `/usr/lib`, `/usr/local/lib`
- С подкаталогами по архитектурам (`arm-linux-gnueabihf/` и др.)

Как увидеть зависимости:
------------------------

::

    ldd ./my_program

Как обновить системный кэш библиотек:
::

    sudo ldconfig

Окружение и отладка:
--------------------

- `LD_LIBRARY_PATH`  путь поиска .so при запуске
- `LD_PRELOAD`  принудительная подгрузка .so с переопределением функций
- `LD_DEBUG=all`  трассировка загрузки библиотек

Пример:
::

    export LD_LIBRARY_PATH=./lib
    ./my_program
